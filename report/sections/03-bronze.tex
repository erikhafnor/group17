\paragraph{Preserve first.}
Every source zip lands byte for byte, read-only, in a path that contains the first twelve
characters of its SHA-256 checksum. An append-only manifest records each file's download
(URL, Last-Modified, size, checksum, run identifier) and its parsing. Before downloading, a HEAD
request compares Last-Modified and size with the manifest; after downloading, a known checksum
means the file is discarded. A rerun of the October 2026 dev ingestion downloaded none of its
eleven files.

\paragraph{Parse without losing records.}
Bronze tables keep every value as the original string; only the encoding changes, from cp1252
to UTF-8. Because records end with CRLF while some fields contain bare line feeds, we read each
file with CRLF as the record separator and check the field count of every record
(Listing~\ref{lst:bronze-parse}). A record with the wrong number of fields is kept, flagged, and
its raw line preserved. This parsed all 183 master records with embedded line feeds as whole
records, where the default reader would have produced 366 broken fragments.

\begin{lstlisting}[caption={Bronze parsing of one source file (simplified).},label={lst:bronze-parse}]
lines = spark.read.option("lineSep", "\r\n").text(path)
fields = lines.select("value", F.split("value", r"\|", -1).alias("f"))
ok = F.size("f") == len(columns)
rows = fields.select(
    *[F.when(ok, F.col("f")[i]).alias(c) for i, c in enumerate(columns)],
    ok.alias("_is_well_formed"),
    F.when(~ok, F.col("value")).alias("_raw_record"))
\end{lstlisting}

\paragraph{Lineage and reruns.}
Each row carries its source file, file kind, publication time, run identifier and ingestion
time. Each source file is written to its own partition, so parsing a file again replaces exactly
that file's rows.
