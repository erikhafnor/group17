\subsection{Version resolution}

A master record is one \emph{version} of a report. Silver keeps the newest version of each
\texttt{mdr\_report\_key}, ordered by date changed, then file kind (change before add before
history), then file publication time (Listing~\ref{lst:versions}). On the October 2026 dev run
this turned 1{,}104{,}177 Bronze rows into 699{,}066 reports, with 405{,}111 superseded
versions.

\begin{lstlisting}[caption={Newest version per report.},label={lst:versions}]
newest_first = Window.partitionBy("mdr_report_key").orderBy(
    F.col("date_changed").desc_nulls_last(),
    F.col("_source_rank").desc(),
    F.col("_source_modified_at").desc_nulls_last())
current = (typed.filter(F.col("_reject_reason").isNull())
    .withColumn("_version", F.row_number().over(newest_first))
    .filter(F.col("_version") == 1))
\end{lstlisting}
